# 故障诊断决策树（练习数据）

> 本文档为虚构教学材料，用于练习远程诊断问答，不作为现场作业依据。
> 结构对应 `故障码表.csv`，章节号可直接作为引用来源。

## 4.1.1 F01 料筒加热圈断路

- 分组：料筒加热　严重度：中
- 报警条件：料筒温度低于设定值 15℃ 以上
- 关键测点：T_BARREL1 偏低
- 典型原因：加热圈长期高温氧化，电阻丝断路。
- 复位方式：更换加热圈后自动恢复
- 涉及备件：P-1201
- 通常是否需要到场：否

先追问：
1. 温度是某一个区偏低还是全部偏低？
2. 是停电后重新开机才出现，还是运行中突然出现？

排查步骤：
1. 对照 HMI 温度画面，判断是哪一区偏低。
2. 用钳形表测该区加热圈电流，正常约 8-12 A。
3. 测加热圈电阻，正常 15-25 Ω；无穷大表示断路。
4. 检查固态继电器输出端是否有 220 V。
5. 更换加热圈后重新升温，观察 10 分钟。

风险提示：温度不足会造成欠注和冷斑，继续生产会产生大批不良品。

## 4.1.2 F02 料筒温度传感器漂移

- 分组：测点信号　严重度：低
- 报警条件：温度反馈与设定长期偏差 10℃ 以上
- 关键测点：T_BARREL1 偏差
- 典型原因：热电偶老化漂移或接线端子氧化。
- 复位方式：更换或重新标定后恢复
- 涉及备件：P-1202
- 通常是否需要到场：否

先追问：
1. 换一支备用热电偶试过吗？
2. 偏差是缓慢变化还是跳变？

排查步骤：
1. 用标准温度计或备用热电偶对比实测温度。
2. 检查热电偶插头是否氧化、接触不良。
3. 在 HMI 参数页执行一次温度标定。
4. 更换热电偶后复测偏差。

风险提示：温度显示不准会误导工艺调整，造成批量不良。

## 4.2.1 F03 液压油温过高

- 分组：液压润滑　严重度：高
- 报警条件：油温 ≥ 55℃ 报警，≥ 60℃ 停机
- 关键测点：T_OIL 偏高
- 典型原因：冷却器脏堵导致换热能力下降。
- 复位方式：油温降至 50℃ 以下后手动复位
- 涉及备件：P-1303
- 通常是否需要到场：是

先追问：
1. 冷却水进出水温差多少？
2. 油温是运行几小时后才升还是开机就高？

排查步骤：
1. 先测冷却水进水温度与流量，判断水路是否正常。
2. 检查冷却器进出油管温差，判断换热效率。
3. 检查油位与油质，油色发黑说明氧化严重。
4. 检查背压阀设定是否过高。
5. 清洗冷却器或按周期换油。

风险提示：油温持续偏高会加速密封老化，引发压力波动和泄漏。

## 4.2.2 F04 液压系统压力不足

- 分组：液压润滑　严重度：高
- 报警条件：系统压力低于额定值 15%
- 关键测点：P_HYD 偏低
- 典型原因：液压泵磨损或溢流阀卡滞导致压力建立不足。
- 复位方式：修复后手动复位
- 涉及备件：P-1101
- 通常是否需要到场：是

先追问：
1. 压力是完全建立不起来，还是保压时掉得快？
2. 系统有没有明显的渗油点？

排查步骤：
1. 读压力表与 HMI 压力值，判断两者是否一致。
2. 检查溢流阀设定与阀芯是否卡滞。
3. 查泵体温度与噪声，判断泵是否磨损。
4. 检查油缸密封与管接头是否渗漏。
5. 测量保压 30 秒的压力降，超过 0.5 MPa 判定内漏。

风险提示：压力不足会造成欠注和保压不稳，直接影响成品尺寸。

## 4.2.3 F05 油泵电机过载

- 分组：驱动电机　严重度：高
- 报警条件：电机电流超额定 110% 持续 10 秒
- 关键测点：C_MOTOR 偏高；T_MOTOR 偏高
- 典型原因：电机轴承磨损导致运行阻力加大而过载。
- 复位方式：热继电器复位后手动启动
- 涉及备件：P-1102
- 通常是否需要到场：是

先追问：
1. 是自动运行时过载，还是手动启动就跳？
2. 电机外壳温度摸上去烫手吗？

排查步骤：
1. 测三相电流是否平衡，偏差超过 10% 说明有异常。
2. 测电机绕组绝缘电阻，低于 1 MΩ 需干燥或更换。
3. 手动盘车检查泵是否卡滞、联轴器是否偏心。
4. 检查热继电器整定值是否与铭牌一致。

风险提示：反复过载会烧毁电机绕组，停机损失大。

## 4.3.1 F06 冷却水流量不足

- 分组：冷却水路　严重度：中
- 报警条件：流量低于额定值 60%
- 关键测点：F_COOL 偏低
- 典型原因：过滤器堵塞或管路结垢导致流量下降。
- 复位方式：清洗过滤器后恢复
- 涉及备件：P-1302
- 通常是否需要到场：是

先追问：
1. 车间其他机器水压是否也低？
2. 过滤器上次清洗是什么时候？

排查步骤：
1. 测进水压力与流量，判断是否厂务水压低。
2. 拆检 Y 型过滤器，检查是否有水垢或杂质。
3. 检查冷却水路是否结垢，必要时酸洗。
4. 确认阀门开度是否正确。

风险提示：冷却不足会连带引起油温高与制品变形。

## 4.4.1 F07 变频器过流过压

- 分组：变频驱动　严重度：高
- 报警条件：变频器报 OC 或 OU 并停机
- 关键测点：变频器故障码
- 典型原因：电网电压波动或参数不匹配导致变频器保护动作。
- 复位方式：排除故障后按变频器复位键
- 涉及备件：P-1103
- 通常是否需要到场：否

先追问：
1. 是启动瞬间报，还是减速时报？
2. 车间电压是否有波动？

排查步骤：
1. 读变频器历史故障码与发生时间。
2. 检查输入电压与直流母线电压。
3. 检查电机电缆绝缘与接线端子。
4. 确认加减速时间参数是否过短。
5. 必要时更换变频器。

风险提示：驱动故障会造成突然停机，模具内制品报废。

## 4.5.1 F08 熔胶螺杆磨损

- 分组：机械传动　严重度：中
- 报警条件：注塑重复精度超差
- 关键测点：T_INJ 波动
- 典型原因：螺杆长期磨损导致塑化与计量不稳定。
- 复位方式：更换螺杆组后恢复
- 涉及备件：P-1401
- 通常是否需要到场：是

先追问：
1. 是最近才开始的，还是逐渐变差？
2. 最近换过料或做过保养吗？

排查步骤：
1. 统计连续 10 模的注塑时间与重量，看离散度。
2. 检查螺杆与料筒间隙，超过 0.35 mm 需更换。
3. 检查止逆环是否磨损、能否可靠封料。
4. 折算实际射胶量与理论值对比。

风险提示：制品重量波动、尺寸超差，客户投诉风险高。

## 4.4.2 F09 编码器信号异常

- 分组：变频驱动　严重度：中
- 报警条件：编码器信号丢失或异常
- 关键测点：V_INJ 波动
- 典型原因：编码器线束接触不良或元件老化。
- 复位方式：重新接线或更换编码器后恢复
- 涉及备件：P-1104
- 通常是否需要到场：否

先追问：
1. 报警是偶发还是每次开合模都报？
2. 最近有没有拆过电机或动过线束？

排查步骤：
1. 检查编码器插头是否松动、线束是否破损。
2. 用示波器看编码器 A/B 相脉冲是否正常。
3. 在驱动器里做一次编码器相位自学习。
4. 更换编码器后复测定位精度。

风险提示：位置反馈错误会导致动作定位不准甚至撞模。

## 4.6.1 F10 安全门限位故障

- 分组：安全互锁　严重度：高
- 报警条件：安全门未闭合禁止锁模
- 关键测点：安全门信号
- 典型原因：限位开关触点氧化或机械位置偏移。
- 复位方式：触点复位后手动复位
- 涉及备件：P-1502
- 通常是否需要到场：否

先追问：
1. 信号是怎么来的：HMI 画面还是现场现象？
2. 门明显关到位了但系统仍说未闭合吗？

排查步骤：
1. 检查限位开关触点是否粘连或氧化。
2. 测量安全门回路通断，确认安全继电器动作。
3. 检查门机械部分是否变形导致压不到位。
4. 更换限位开关后重新验证互锁功能。

风险提示：安全互锁失效属于安全问题，必须处理到位。

## 4.7.1 F11 干燥机不启动

- 分组：工艺周期　严重度：低
- 报警条件：无报警，仅不动作
- 关键测点：无
- 典型原因：控制回路保险熔断导致干燥机不上电。
- 复位方式：重新上电后恢复
- 涉及备件：P-1601
- 通常是否需要到场：否

先追问：
1. 干燥机面板有显示吗？
2. 同一路电源上其他设备是否正常？

排查步骤：
1. 确认电源开关与断路器状态。
2. 检查干燥机控制保险是否熔断。
3. 检查控制柜内接触器是否吸合。
4. 测量加热管与风机电阻。

风险提示：原料未干燥会造成银纹、气泡等外观缺陷。

## 4.7.2 F12 周期超时

- 分组：工艺周期　严重度：低
- 报警条件：单模周期超设定上限 20%
- 关键测点：CYCLE_TIME 偏高
- 典型原因：动作参数设定偏保守，叠加期间节拍下降。
- 复位方式：处理后自动恢复
- 涉及备件：无
- 通常是否需要到场：否

先追问：
1. 是全部动作都慢，还是某一个动作慢？
2. 最近调整过速度或压力参数吗？

排查步骤：
1. 读周期分解时间，定位是哪个动作变慢。
2. 对比历史周期趋势，判断是渐变还是突变。
3. 检查对应动作的压力与速度设定。
4. 检查该动作的阀件或伺服响应。

风险提示：节拍下降导致产能不达标。

## 4.8.1 F13 通信中断

- 分组：通讯总线　严重度：中
- 报警条件：通讯超时
- 关键测点：遥测缺失
- 典型原因：网线接头氧化或交换机端口不稳定。
- 复位方式：重新插拔或更换线缆后恢复
- 涉及备件：P-1603
- 通常是否需要到场：否

先追问：
1. 是这一台掉线还是整条线都掉？
2. 现场有人在设备附近施工吗？

排查步骤：
1. 检查网线接头与交换机端口指示。
2. ping 设备 IP 判断链路连通性。
3. 检查网关参数与 IP 是否冲突。
4. 更换网线后观察 30 分钟。

风险提示：数据缺失期间无法远程监视，需现场确认设备状态。

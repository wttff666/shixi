# 诊断数据集与工具服务

本目录提供远程诊断所需的初始数据集和只读 MCP 工具服务。产品后端通过进程与
配置连接，不直接读取数据文件。

## 本目录文件

| 文件 | 说明 |
| --- | --- |
| `domain.py` | 领域定义：机型、故障树、测点、备件、客户站点与注入事件 |
| `run.py` | 数据集生成器（纯标准库、种子固定、可复现） |
| `校验.py` | 生成后自检：事件窗口外不应越限、报警应可回溯 |
| `mcp_server.py` | 只读 MCP 工具服务（stdio JSON-RPC），读取 `数据包/` |
| `数据包/` | 生成的数据文件，见下表 |
| `README.md` | 本文件 |

## 运行

```powershell
cd D:\shixi\zuoye\remotediag
..\.venv\Scripts\python.exe run.py        # 重新生成数据集
..\.venv\Scripts\python.exe 校验.py       # 自检
```

## MCP 工具服务

由产品后端的 `services/mcp_gateway.py` 以子进程方式启动，数据目录通过环境变量
`DATA_PACK_DIR` 指定。提供的工具：

| 工具 | 说明 |
| --- | --- |
| `device_profile` | 设备档案（客户、机型、出厂编号、保修与配置） |
| `device_latest` | 设备最新一个采样点的测点值 |
| `device_telemetry` | 指定时间窗的测点趋势 |
| `device_active_faults` | 数据窗口内判定为真实故障的报警 |
| `alarm_history` | 历史报警（含误报） |
| `tickets_search` / `tickets_get` | 历史工单检索与详情 |
| `fault_tree_lookup` | 故障树查询（现象 → 故障、章节与处置） |
| `spare_part_lookup` | 备件查询（物料号、库存、货期） |
| `service_bulletin_lookup` | 服务通报查询 |
| `warranty_lookup` | 保修与服务等级查询 |

全部为只读工具，写操作不经过本服务。

## 数据包内容

| 文件 | 内容 |
| --- | --- |
| `客户与站点.csv` | 客户站点、客户等级与服务等级 |
| `设备主表.csv` | 18 台设备档案（4 个机型，6 个客户站点） |
| `保修与服务合同.csv` | 每台设备的保修与 SLA |
| `故障码表.csv` | 13 个故障的报警条件、涉及备件与是否到场 |
| `故障树.md` | 每个故障的追问问题、排查步骤与风险 |
| `测点表.csv` | 22 个工艺与状态测点定义 |
| `备件物料清单.csv` | 15 个备件及适用机型 |
| `服务通报.csv` | 3 条批次性服务通报 |
| `遥测_M***_202607.csv` | 六台设备 2026-07 的 15 分钟采样时序 |
| `报警记录.csv` | 阈值扫描得到的报警（含 1 条标注误报） |
| `工单_知识库.csv` | 42 条历史工单 |
| `工单_测试集.csv` | 15 条评测用例与标准答案 |
| `主数据说明.md` | 生成结果说明、事件清单与已知局限 |

## 与风电场版本的差异

相比单机型、单客户的版本，本数据集增加了多客户与多机型、保修与 SLA 层、
备件与 BOM、批次性服务通报、信息不足样本与误报样本，用于练习厂商侧的远程诊断。

## 已知局限

- 数据为合成生成，参数不代表真实机型。
- 遥测覆盖六台设备，其余设备工单没有对应时序。
- 报警扫描逻辑较简单，未模拟真实平台的复杂滤波。

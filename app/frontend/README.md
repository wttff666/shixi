# 前端

原生 HTML/CSS/JS，无构建工具，由后端静态托管。

| 文件 | 说明 |
| --- | --- |
| `index.html` | 诊断工作台主页面（工单选择、设备检索、诊断卡片、引用抽屉） |
| `app.js` | 诊断工作台交互：关联工单、流式诊断、内部/对外分层渲染、复制话术、设备选择、会话历史 |
| `data.js` | 常用场景预设（示例设备与描述） |
| `api.js` | 登录态存取、带 Cookie 的请求封装、登出 |
| `service.html` / `service.js` | 服务工单台：登记来电、工单列表、工单详情、状态流转、派工建议与对客户说明 |
| `portal.html` / `portal.js` | 客户服务门户（只读）：本企业设备档案与保修、服务记录与处理反馈 |
| `diagnosis.css` | 诊断与工单专用样式（诊断卡片、派工建议、内部备注、对客户说明、设备列表等） |
| `styles.css` | 全站基础样式（布局、侧栏、消息、表单、管理页） |
| `login.html` / `login.js` | 登录页与交互（含首次登录改密） |
| `documents.html` / `documents.js` | 知识库与资料页：上传、切片预览、发布、OCR 校对 |
| `skills.html` / `skills.js` | 诊断 Skill 页：上传、发布、停用 |
| `users.html` / `users.js` | 用户管理页：新增、角色调整、停用、重置密码 |

页面按角色控制可见入口：客户账号登录后直接进入只读门户，不显示诊断与工单入口；
非系统管理员看不到用户管理。

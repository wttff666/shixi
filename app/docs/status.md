# 当前开发状态

## 已完成

- FastAPI 后端与 SQLite 数据模型，支持切换 PostgreSQL + pgvector。
- 诊断工作台、知识库与资料、诊断 Skill、用户管理四个页面。
- 设备档案、客户、保修与服务合同、备件、服务通报、故障树、历史工单的主数据。
- 从诊断数据集自动导入主数据并构建检索知识切片。
- 只读 MCP 工具服务（设备档案、状态、遥测、报警、工单、故障树、备件、通报、保修）。
- 混合检索：词法召回 + BGE-M3 向量召回。
- 结构化诊断：故障 ID、原因、处置、手册章节、是否到场、备件与保修判定。
- 服务工单：接单、编号、状态流转，诊断结论与派工建议回写工单。
- 派工建议面板：远程 / 上门、SLA 时限、预计工时（含同类工单依据）、建议备件、二线复核提示。
- 信息分层输出：内部备注与「对客户说明」分开，对外话术可一键复制且不含内部字段。
- 客户账号退回只读：只能查询本企业设备档案与服务记录，不能发起诊断或建单。
- 信息不足时的追问机制与"待确认"结论。
- 服务通报命中提示与批次性免费判定。
- 多客户数据隔离（客户账号只能访问本企业设备）。
- 六类角色权限、Cookie 会话、密码策略与强制退出。
- 诊断运行、模型调用、工具调用与管理操作审计。
- 服务质量指标接口与诊断评测（15 条用例）。
- 扫描件 OCR 与逐页人工校对。
- 声明式 Skill（JSON / Markdown / ZIP 上传、校验、发布、停用）。
- 后台任务与任务状态查询。
